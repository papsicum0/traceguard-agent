# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

TraceGuard takes agent and infrastructure security seriously. If you identify an issue involving input sanitization, prompt injection bypassing, or cryptographic validation failures:

1. **Do not open a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories on this repository or contact the maintainer directly.
3. Include clear steps to reproduce, the observed behavior, and the expected behavior.

We aim to acknowledge reports within 48 hours and provide remediation in a timely manner.
